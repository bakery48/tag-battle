# Tag Battle - タグバトル

## ゲーム概要

Tag Battleは2人対戦のカードバトルゲームです。各プレイヤーはフロント（前衛）とリア（後衛）の2体のモンスターを選び、独自のデッキを構築してターン制のバトルを行います。

- **2人対戦**: Socket.ioによるリアルタイムオンライン対戦
- **4フェーズ制**: ピック → ドラフト → 並び替え → バトル
- **20種のモンスター**: フロント10体、リア10体
- **戦略的なデッキ構築**: ドラフトによるカード選択

## セットアップ

```bash
# 依存パッケージのインストール
pnpm install

# 開発サーバー起動（サーバー + クライアント同時起動）
pnpm dev
```

サーバーは `http://localhost:3001`、クライアントは `http://localhost:5173` で起動します。

## ゲームフロー

### 1. ピックフェーズ (Pick)
各プレイヤーがフロントモンスター1体とリアモンスター1体を選択します。

### 2. ドラフトフェーズ (Draft)
各プレイヤーは自分のモンスター専用のカードプールからカードをドラフトしてデッキを構築します。フロント8枚 + リア8枚 = 合計16枚のデッキを作成します。ただし各ターンのバトルでは前衛のカード4枚を使用します。

### 3. 並び替えフェーズ (Arrange)
デッキのカード順序を決定します。

### 4. バトルフェーズ (Battle)
各ターン、両プレイヤーが同時にカードを選択して効果を解決します。

## 技術スタック

| 項目 | 技術 |
|------|------|
| バックエンド | Node.js + Express + Socket.io |
| フロントエンド | React 18 + Vite |
| 状態管理 | Zustand |
| 型システム | TypeScript (strict) |
| バリデーション | Zod |
| テスト | Vitest |
| パッケージ管理 | pnpm workspaces |

## ディレクトリ構成

```
tag-battle/
├── packages/
│   ├── shared/          # 共有型定義・ゲームロジック
│   │   └── src/
│   │       ├── types.ts           # 型定義
│   │       ├── monsters.ts        # モンスターマスターデータ
│   │       ├── battleResolver.ts  # バトル解決ロジック
│   │       ├── adapters/          # 表示用アダプター
│   │       └── cards/             # カードデータ (モンスター別)
│   ├── server/          # ゲームサーバー
│   │   └── src/
│   │       ├── index.ts           # エントリーポイント
│   │       ├── GameRoom.ts        # ゲームルーム管理
│   │       ├── RoomManager.ts     # ルームマネージャー
│   │       ├── events.ts          # Socket.ioイベント定義
│   │       └── validation/        # Zodバリデーション
│   └── client/          # Reactクライアント
│       └── src/
│           ├── screens/           # 画面コンポーネント
│           ├── phases/            # フェーズUI
│           ├── components/        # 共通コンポーネント
│           ├── store/             # Zustand状態管理
│           └── hooks/             # カスタムフック
└── tsconfig.base.json
```
